# Festival Mode

The festival calendar (Diwali/Pongal/Christmas dates, 2012–2018) is **synthetic/demo**, not derived
from real festival-day traffic records for this location. Every Festival Mode response is therefore
explicitly labeled `"Scenario / Demo Forecast"` in both the API payload and the UI, per RULE 16 — we
do not claim the model learned real Diwali/Pongal/Christmas behaviour.
